How to turn this into a PDF · كيف تحوّلها إلى PDF

اضغط Ctrl + P ثم اختر «حفظ كملف PDF»
English
  1. Open any page (a chapter, the questions, or the cheat sheet).
  2. Press Ctrl + P (Windows) or ⌘ + P (Mac).
  3. Set Destination → Save as PDF, paper A4, margins Default.
  4. Tick Background graphics so colours, tables and figures are kept.
  5. Tip: choose “English only” before printing if you want an English-only revision copy. In print mode all quiz answers are shown automatically.
العربية
  1. افتحي أي صفحة (فصل، أو الأسئلة، أو الملخص).
  2. اضغطي Ctrl + P على ويندوز أو ⌘ + P على ماك.
  3. اختاري الوجهة ← حفظ كملف PDF، الورق A4، الهوامش افتراضية.
  4. فعّلي خيار رسومات الخلفية (Background graphics) حتى تُحفظ الألوان والجداول والصور.
  5. ملاحظة: اختاري «English only» قبل الطباعة إذا أردتِ نسخة مراجعة إنجليزية فقط. وفي وضع الطباعة تظهر إجابات الأسئلة تلقائياً.
