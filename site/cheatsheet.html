🪜 The 5 hacking phases (EC-Council)مراحل الاختراق الخمس

1. ReconnaissanceGather evidence and information on the targets
الاستطلاع — جمع الأدلة والمعلومات
2. Scanning & enum.Actively apply tools for in-depth information
الفحص والتعداد — تطبيق الأدوات بشكل نشط
3. Gaining accessTrue attacks are leveled against the targets
الحصول على الوصول — شن الهجمات الحقيقية
4. Maintaining accessEnsure a way back in — leave back doors open
الحفاظ على الوصول — ترك أبواب خلفية
5. Covering tracksRemove/alter log files, hide files
تغطية الآثار — حذف السجلات وإخفاء الملفات

🚩 TCP flags, states & ICMPالأعلام والحالات و ICMP

SYNInitial communication establishment (negotiates seq. numbers)
بدء الاتصال والتفاوض على أرقام التسلسل
ACKAcknowledgment; set on all segments after the initial SYN
إقرار؛ مضبوط على كل المقاطع بعد SYN
RSTForces termination in both directions
يفرض الإنهاء في الاتجاهين
FINOrdered close to communications
إغلاق منظّم
PSHDeliver data without waiting for buffering
تسليم دون انتظار التخزين المؤقت
URGData sent out of band
بيانات خارج النطاق
Flag size1 bit each — 6 flags total; 1 = on
بت واحد لكل عَلَم — ٦ أعلام؛ ١ = مُفعّل
HandshakeSYN (Seq=x) → SYN-ACK (Ack=x+1, Seq=y) → ACK (Ack=y+1)
LISTENINGWaiting for an incoming connection
في انتظار اتصال وارد
ESTABLISHEDActive connection between two hosts
اتصال نشط
CLOSE_WAITRemote host has closed the connection
الجهاز البعيد أغلق الاتصال
TIME_WAITLocal host closed, waiting for delayed packets
المحلي أغلق وينتظر الحزم المتأخرة
ICMP 0 / 3 / 8Echo Reply / Destination Unreachable / Echo Request
رد الصدى / تعذّر الوصول / طلب الصدى
netstat -anView port states in Windows
عرض حالات المنافذ في ويندوز

🎯 Scan types & responsesأنواع الفحص والردود

TCP Connect= Full Open Scan · completes handshake · reliable · easily detected
مفتوح كامل · موثوق · سهل الاكتشاف
SYN Scan= Half-Open / Stealth · faster · harder to detect · most used
نصف مفتوح/خفي · أسرع · أصعب اكتشافاً
FIN / NULL / XMAS= Inverse TCP Flag Scan · bypass simple firewalls
أعلام عكسية · تجاوز جدران بسيطة
Idle Scan= Zombie Scan · uses idle host's IPID to hide attacker IP
زومبي · يستخدم IPID لإخفاء المهاجم
FIN flagsFIN
NULL flagsNo flags
XMAS flagsFIN + PSH + URG
Open port →No Response
لا يوجد رد
Closed port →RST

📡 Sniffing (Ch 4)التنصت

MAC address48 bits (6 bytes) · 12 hex digits · Layer 2 (Data Link)
٤٨ بت · ١٢ رقماً ست عشرياً · الطبقة الثانية
Collision domainSegment where packets can collide — shared coax / repeater hub
جزء تتصادم فيه الحزم — كابل أو Hub مشترك
Clear-text protocolsHTTP · FTP · TFTP · Telnet · SMTP · POP3
بروتوكولات غير مشفّرة
Secure alternativesHTTPS · SFTP · SSH
ARPMaps IPv4 → MAC · Request = broadcast · Reply = unicast
يربط IPv4 بـ MAC · الطلب بث · الرد أحادي
Passive sniffingNo modification · hub-based · same collision domain · hard to detect · useless on switches
بلا تعديل · شبكات Hub · صعب الاكتشاف · غير فعال على المحوّلات
Active sniffingSwitched networks · redirect/duplicate packets · may need admin access
شبكات مُبدَّلة · إعادة توجيه أو نسخ الحزم
4 active techniquesMAC Flooding · ARP Spoofing · Port Mirroring (SPAN) · DHCP Starvation
CAM tableSwitch DB mapping MAC → port; when full → switch acts like a hub
يربط MAC بالمنفذ؛ عند امتلائه يتصرف كالـ Hub
ARP spoofing impactMitM · sniffing in switched nets · data theft / session hijacking
هجوم الوسيط · سرقة بيانات · اختطاف جلسات
DHCP starvationA DoS — exhausts the DHCP address pool
حجب خدمة — استنفاد مجمّع العناوين
Sniffing toolsWireshark (capture & protocol analysis) · Ettercap (MitM) · EtherPeek · Snort (IDS)
